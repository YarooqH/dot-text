How the dots move

  1. Step 1

    Sample the word

    The word is drawn once on a hidden canvas. A grid is laid over the letters (hex for dots, square for pixels) and its spacing is tuned until as close to 1,200 points as possible land on the ink. Any dots left over stack on existing points, so every word uses the whole set.

  2. Step 2

    Pair old dots with new spots

    Both sets are sorted left to right and cut into thin strips, then matched top to bottom inside each strip. Dots that start next to each other land next to each other, so the change reads as one movement. Swarm mode shuffles the pairs instead.

  3. Step 3

    Fly on a curve

    Each dot follows its own bowed path. Start times sweep from the left edge of the word to the right, dots shrink slightly and take the accent color mid-flight, and a new word can interrupt a flight at any point.

Use it

const dots = dotText(canvas, {
  count: 1200,
  shape: "circle",  // "square" for pixels, "emoji" for emoji
  emoji: "🍓🍒",    // used when shape is "emoji"
  dot: 0.34,        // size; 0.5 = neighbors touch
  mode: "flow",     // or "swarm"
  color: "#13161c",
  accent: "#2c4fe0",
});

dots.set("hello");
dots.set("world"); // same 1,200 dots, new word

Other options: font, padding, duration, stagger, arc, pointer, onTick. Change them later with dots.options({...}).
